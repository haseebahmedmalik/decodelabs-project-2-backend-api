Communicating State: Essential Status Codes

Don't force the client to guess. Use semantic response codes for absolute integrity.

201

Created

Resource successfully provisioned.

204

No Content

Successful request with no body returned.

400

Bad Request

Syntactic or validation failure.

401

Unauthorized

Authentication credentials missing/invalid.

403

Forbidden

Insufficient authorization scope.

404

Not Found

Requested resource does not exist.

429

Too Many Requests

Rate limit threshold exceeded.

500

Internal Error

Server-side execution fault.
