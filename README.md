# DecodeLabs | Project 2: Backend API Development

## Overview

This repository contains a professional single-page web application developed for the **DecodeLabs Full Stack Development Industrial Training Kit - Project 2: Backend API Development**.

The project focuses on backend API concepts, RESTful architecture, HTTP methods, data validation, status codes, security, stateless communication, and API request handling.

## Features

* Responsive single-page web interface
* Bootstrap 5 integration
* Professional dark blue and black color scheme
* RESTful HTTP methods overview
* IPO architecture model
* JSON data exchange example
* Interactive API validation simulation
* HTTP status code reference
* Authentication and authorization concepts
* Security and resilience concepts
* Smooth scrolling navigation
* Mobile-friendly layout

## Project Structure

* `index.html` - Main HTML file containing the complete single-page website structure.
* `style.css` - Custom stylesheet containing the dark professional theme, colors, typography, cards, buttons, forms, and responsive visual styling.
* `script.js` - JavaScript functionality for API validation simulation and smooth scrolling navigation.
* `README.md` - Project documentation.

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Bootstrap 5
* Font Awesome
* Google Fonts

## Running the Website

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` directly in a browser, or use **Live Server** for local development.
4. Navigate through the sections and test the API validation form.

## API Validation Simulation

The validation form demonstrates basic API request handling.

It checks:

* Required username input
* Required email input
* Successful request response
* HTTP `400 Bad Request`
* HTTP `201 Created`
* Structured JSON-style responses
